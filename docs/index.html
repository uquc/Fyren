确定性模拟

GameWorld.update() 每帧按 playerId 排序输入，不使用浮点 RNG——保证 Java strictfp 下所有客户端计算一致。

GGPO 式回滚

乐观帧锁定，预测执行 + 状态快照。远程输入校验不通过时回滚最多 10 帧，用已确认输入重新模拟。

P2P 降级策略

对称 NAT 下 UDP 打洞自动回退服务器中继。纯 Java 实现，零外部 STUN/TURN 依赖。

跨协议匹配池

UDP 客户端和 WebSocket 浏览器共享同一个 MatchManager 实例。MatchResponseSender 接口解耦传输层。
